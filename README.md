# Summary

Create scatter / line plots of scientific data from an Excel (.xlsx) file. Easily perform common analytical tasks such as Pearson correlation, linear regression and log10 transformation. Automatically infers x-axis and y-axis information from your README sheet. Save your preferences with the Save & Exit button.

# Prerequisites

- Download the latest Windows (.exe) or Linux release for the **Releases** section

- Data must be stored as an Excel (.xlsx) file. A <b>README</b> Sheet is required with one column representing the parameter name (unit name) and another column representing the unit. **Example README:**

| Parameter | Unit |
|-----------|------|
| Date      |      |
| Volume    | mL   |
| Length    | m    |

- The **DATA SHEET** must contain a row with column labels. Ensure columns contain consistent types. **Example DATA:**

| id | name     | type  | discharge |
|----|----------|-------|-----------|
| 1  | bridge_a | river | 15        |
| 2  | bridge_b | river | 22        |
| 3  | bridge_c | lake  | 13        |
